# 03: 浏览器音频转码（mp3/m4a/ogg）

**What to build:** 用户在工作台选择常见的非 WAV 音频（mp3、m4a、ogg 等）时，浏览器自动解码并重采样为 16kHz 单声道 PCM16 WAV 再提交，用户不需要事先手动转换。浏览器无法解码的文件会在该文件上直接报错，不会发出请求。后端与部署镜像不引入 ffmpeg 或其它音频依赖。

**Blocked by:** 02: 单文件语音转写（WAV 上传）

**Status:** ready-for-agent

- [ ] 选择 mp3、m4a、ogg、wav 等浏览器可解码的音频时，自动转码为 16kHz 单声道 PCM16 WAV 后上传
- [ ] 转码后仍以原始文件名提交，任务记录与导出文件名保持原音频名
- [ ] 浏览器无法解码的文件单独标记失败，错误明确指出「浏览器无法解码该音频」，且不发起转写请求
- [ ] 重采样与 WAV 编码实现为纯函数，与浏览器解码适配层分离
- [ ] 纯函数测试覆盖采样率、单声道下混、WAV 头长度与数据长度
- [ ] 后端与部署环境不新增 ffmpeg 或音频处理依赖
- [ ] 转码期间该文件显示明确的进行中状态，不阻塞其它文件
- [ ] 页面文案支持中英文
