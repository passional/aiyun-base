# 05: 转写历史与结果导出

**What to build:** 用户在语音工作台看到按本人隔离、分页的转写历史；每条记录展示原文件名、大小、时长、模型、状态、耗时与创建时间。打开详情可以看到完整的转写文本与分段，并复制或导出 `.txt`。用户可以删除单条记录，也可以批量删除；删除为软删除，原始音频本来就不保存，因此没有文件需要清理。

**Blocked by:** 02: 单文件语音转写（WAV 上传）

**Status:** ready-for-agent

- [ ] 历史列表只返回当前用户创建的转写任务，分页展示
- [ ] 列表展示原文件名、大小、时长、模型、状态、耗时与创建时间
- [ ] 详情展示完整转写文本与带起止时间的转写分段
- [ ] 详情支持复制全文与导出 `.txt`，导出文件名取原音频名
- [ ] 支持单条软删除
- [ ] 支持批量软删除
- [ ] 用户不能查看或删除其他用户的转写任务，越权请求返回业务错误
- [ ] 删除后的记录不再出现在列表与详情中
- [ ] 历史列表、详情、删除 API 测试覆盖用户隔离、分页、软删除与权限
- [ ] 页面文案支持中英文
