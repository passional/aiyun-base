# 01: 语音服务与模型配置

**What to build:** 管理员打开「语音工作台 → 语音服务配置」，可以登记语音服务（名称、调用凭证、状态、备注）与其下的语音识别模型（展示名、上游模型标识、资源标识、完整端点 URL、单文件大小上限、音频时长上限、状态、备注）。列表只回显脱敏凭证；编辑时留空凭证表示沿用原值；被模型引用的服务、被转写任务引用的模型不能删除，只能停用。系统预置一条火山引擎语音服务（凭证留空）与一个默认 ASR 模型，管理员填 key 即可使用。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 新增语音服务与语音识别模型的数据结构及迁移，迁移自动生成零差异
- [ ] 预置「火山引擎语音」服务（凭证为空）与默认 ASR 模型（模型标识、资源标识、默认端点、默认限额），初始化后管理员只需填 key
- [ ] 管理员菜单出现「语音工作台 → 语音服务配置」，配置读写受独立权限控制
- [ ] 服务支持列表、下拉选项、详情、新增、编辑、停用、删除
- [ ] 模型支持列表、下拉选项、新增、编辑、停用、删除，并可按所属服务筛选
- [ ] 凭证落库前加密；任何出参只给掩码与「是否已配置」，不回显明文或密文
- [ ] 编辑服务时凭证留空保留原值；填写新值则替换
- [ ] 被模型引用的服务、被转写任务引用的模型删除时返回可读业务错误，并提示改为停用
- [ ] 模型的端点 URL、模型标识、资源标识、大小上限、时长上限可编辑且做非空/范围校验
- [ ] 配置 API 测试覆盖：密文落库、掩码回显、留空保留、删除保护、权限与用户可见性
- [ ] 页面文案支持中英文
